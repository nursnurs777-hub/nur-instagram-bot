# KopKop AI — ИИ-продавец в Instagram Direct

Бот отвечает клиентам в директе магазина: консультирует, берёт цены из Google Sheets, оценивает Trade-in и считает доплату. Если в переписку вмешивается живой менеджер, бот уступает ему.

```
Клиент → Instagram Direct → Meta Webhook → Render (FastAPI) → Claude + инструменты → ответ в Direct
                                                 │
                                   Google Sheets (прайс + «Закуп б/у»), Postgres (история диалогов)
```

## Что умеет

- **Цены.** Берёт их только из таблицы, листы `iphone`, `iPad`, `MacBook` и другие. Строки с «Показать = Нет» не видит. Варианты SIM + eSIM и «только eSIM» различает. Если цена в строке пустая, сумму не называет.
- **Trade-in.** Базовую цену берёт из листа «Закуп б/у», вычеты считает по правилам из раздела 11 промпта. Расчёт делает код, а не модель. Оценка сохраняется в карточке диалога, поэтому при вопросе о доплате бот не переспрашивает про старый телефон.
- **Пауза при ответе менеджера.** Если менеджер ответил вручную, бот молчит 5 минут, и каждый новый ответ менеджера продлевает паузу. Если клиент написал во время паузы, а менеджер так и не ответил, после паузы бот ответит сам. Свои сообщения бот распознаёт по `message_id`, поэтому на собственные ответы не реагирует.
- **Склейка сообщений.** Если клиент шлёт несколько сообщений подряд, бот ждёт 4 секунды и отвечает на все одним ответом.
- **Фото.** Бот их видит. На голосовые вежливо просит написать текстом: расшифровки пока нет.
- **Характеристики техники.** Бот может искать их на apple.com, это нужно для моделей, вышедших после обучения модели.
- **Напоминания.** Одно напоминание через 3 часа, только с 10:00 до 20:00 и только в пределах 23 часов после последнего сообщения клиента. По умолчанию выключены: `FOLLOWUP_ENABLED`.

## Структура

| Файл | Что внутри |
|---|---|
| `prompts/system_prompt.md` | Системный промпт: здесь меняется поведение бота |
| `app/main.py` | Вебхук, админка, страницы `/privacy` и `/data-deletion` для App Review |
| `app/processor.py` | Склейка сообщений, пауза менеджера, планировщик |
| `app/agent.py` | Вызов Claude и цикл инструментов |
| `app/tools.py` | Инструменты модели: поиск, цена, Trade-in, доплата |
| `app/tradein.py` | Правила вычетов Trade-in: суммы меняются здесь |
| `app/catalog.py` | Разбор таблицы и распознавание «айфон 17 про макс есим» |
| `app/sheets.py` | Загрузка Google Sheets, кеш на 5 минут |
| `app/instagram.py` | Подпись вебхука, разбор событий, отправка сообщений |

## Запуск: по шагам

### 1. GitHub

```bash
git init && git add . && git commit -m "KopKop AI"
git branch -M main
git remote add origin https://github.com/<вы>/kopkop-ai.git
git push -u origin main
```

### 2. Доступ к Google Sheets (сервисный аккаунт)

1. Откройте [console.cloud.google.com](https://console.cloud.google.com), создайте проект и включите в нём **Google Sheets API**.
2. Перейдите в IAM → Service Accounts → Create, затем Keys → Add key → JSON и скачайте файл.
3. В таблице «Price NUR» нажмите «Настройки доступа» и добавьте email сервисного аккаунта (`…@….iam.gserviceaccount.com`) с правом **Читатель**.
4. Содержимое JSON-файла целиком вставьте в переменную `GOOGLE_SERVICE_ACCOUNT_JSON`.

Есть и более простой способ: открыть таблицу «всем, у кого есть ссылка», создать API-ключ и указать его в `GOOGLE_API_KEY`. Но тогда прайс сможет посмотреть любой, у кого есть ссылка.

### 3. Render

1. На [render.com](https://render.com) выберите New → **Blueprint** и подключите репозиторий. Render прочитает `render.yaml` и создаст веб-сервис и базу Postgres.
2. Введите секреты: `ANTHROPIC_API_KEY`, `GOOGLE_SERVICE_ACCOUNT_JSON` и `IG_*`. Их можно заполнить позже, после шага 4.
3. После деплоя проверьте, что `https://<сервис>.onrender.com/health` отвечает `{"ok":true}`.
4. Значение `IG_VERIFY_TOKEN` Render сгенерирует сам. Скопируйте его из Environment, оно понадобится на шаге 4.

### 4. Meta for Developers

1. Instagram магазина должен быть **профессиональным** аккаунтом: «Бизнес» или «Автор».
2. На [developers.facebook.com](https://developers.facebook.com/apps) выберите Create App, тип **Business**.
3. Добавьте продукт **Instagram** и откройте **API setup with Instagram login**.
4. Нажмите **Generate access tokens** и подключите аккаунт магазина. Скопируйте токен в `IG_ACCESS_TOKEN`, а ID аккаунта в `IG_ACCOUNT_ID`.
5. **Instagram app secret** с этой же страницы скопируйте в `IG_APP_SECRET`.
6. В разделе **Configure webhooks** заполните поля:
   - Callback URL: `https://<сервис>.onrender.com/webhook`
   - Verify token: значение `IG_VERIFY_TOKEN`
   - Нажмите Verify and save, затем подпишитесь на поля **messages** и **message_echoes**.
7. В Instagram-приложении на телефоне откройте Настройки → Сообщения → «Разрешить доступ к сообщениям» для подключённых инструментов.

### 5. Тест до App Review

Пока приложение в режиме **Development**, бот отвечает только людям с ролью в приложении. Добавьте тестировщиков в App roles → Roles → Instagram Testers и подтвердите приглашения в Instagram.

1. Напишите в директ магазина с тестового аккаунта.
2. В логах Render появится его IGSID. Укажите его в `ALLOWED_USER_IDS`: так бот гарантированно не ответит реальным клиентам, пока вы тестируете.
3. Прогоните сценарии: цена с уточнением памяти и SIM, Trade-in с последующей доплатой, казахский язык, ответ менеджера вручную (бот должен замолчать).

### 6. App Review → Live

1. Запросите **Advanced Access** для `instagram_business_basic` и `instagram_business_manage_messages`. Понадобятся скринкаст работы бота и описание сценария.
2. Privacy Policy URL: `https://<сервис>.onrender.com/privacy`. Data deletion URL: `https://<сервис>.onrender.com/data-deletion`.
3. Пройдите Business Verification.
4. После одобрения переключите приложение в **Live**, а `ALLOWED_USER_IDS` очистите.

## Локальная разработка

```bash
pip install -r requirements-dev.txt
pytest                                   # 35 тестов, в том числе на реальном прайсе
cp .env.example .env                     # заполните ANTHROPIC_API_KEY
set -a; source .env; set +a
python -m scripts.chat --price-file tests/fixtures/price_nur.txt   # чат с ботом в терминале
uvicorn app.main:app --reload            # сервер на :8000
```

## Админка

Все запросы отправляются с заголовком `X-Admin-Token: <ADMIN_TOKEN>`.

| Запрос | Действие |
|---|---|
| `POST /admin/manual/{IGSID}?on=true` | Полностью выключить бота в этом диалоге; `on=false` включает обратно |
| `GET /admin/conversation/{IGSID}` | История и карточка диалога |
| `POST /admin/reload-catalog` | Перечитать прайс сразу, не дожидаясь 5 минут |
| `GET /admin/stats` | Статистика по диалогам и каталогу |

Чтобы выключить бота везде сразу, задайте `BOT_ENABLED=false` в Environment на Render.

## Важные оговорки

- **Цены.** Таблица кешируется на 5 минут: после правки прайса бот увидит новые цены в течение 5 минут или сразу после `/admin/reload-catalog`.
- **Новые листы.** Подхватываются автоматически, если в них есть колонки «Модель» и «Цена». Колонка «Показать» необязательна.
- **Автоответы Meta.** Приветственные сообщения и ice breakers тоже приходят как echo, и бот поставит себя на паузу, приняв их за ответ менеджера. Если они включены, лучше их отключить.
- **Только один воркер.** Склейка сообщений и блокировки живут в памяти процесса, поэтому `--workers 1` и одна копия сервиса. Для нескольких копий понадобится Redis.
